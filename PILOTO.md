## Cómo publicar un enlace (gratis)

### Opción A — Netlify Drop (más rápido, ~1 minuto)
1. Entra a https://app.netlify.com/drop
2. Arrastra la carpeta **geometrics** completa
3. Te da un enlace tipo `https://algo-random.netlify.app`
4. Compártelo con los estudiantes/docentes de la prueba

### Opción B — GitHub Pages
1. Crea un repositorio en GitHub y sube la carpeta `geometrics`
2. Settings → Pages → Branch: `main` / root
3. El enlace será `https://TU_USUARIO.github.io/NOMBRE_REPO/`

## Importante para el piloto
- Cada persona usa su propio navegador; los datos se guardan en **localStorage** de ese equipo.
- En esta versión piloto **no hay servidor central**: las tareas/chats de un PC no se ven en otro.
- Para un piloto real multi-usuario en la nube haría falta un backend (Firebase, Supabase, etc.).
